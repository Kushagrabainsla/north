TaskWindow is installed in Chrome

It lets a coding agent drive the tabs you are signed into. One more piece runs on your machine: a small daemon the agent talks to.

Checking for the daemon…
  1. Open a terminal and run (needs Node 18+): 
    npm install -g taskwindow
taskwindow install
    The installer asks which coding agents to connect, starts the daemon as a login service, and finds this extension.
  2. Come back here. This page turns green on its own; nothing to click in Chrome.
  3. Ask your agent: "Open example.com in a new tab and take a screenshot."

Already ran that? taskwindow doctor says what is wrong. Details in the README.
