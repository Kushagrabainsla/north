# north news briefings

This folder holds the daily news digests produced by the north `news_briefing` agent.

NOTE: The agent's sandbox restricts file writes to this workspace root
(`/Users/kbainsla/Desktop/projects/north`). The canonical path specified by the
briefing task is `~/.north/news/YYYY-MM-DD.md`. When you run the agent outside a
sandbox, that path is the intended destination. Within this sandbox, digests are
written here under `news/YYYY-MM-DD.md` instead.
