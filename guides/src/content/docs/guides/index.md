Each guide shows how to do one task with north.

## Start here

- [Quickstart](/north/guides/quickstart/): install north, connect an AI provider and run your first task.

## Connect

- [Connect your browser](/north/guides/connect-your-browser/): let north do web tasks in your own Chrome profile or in a separate one.
- [Use north from Telegram](/north/guides/telegram/): send tasks and answer cards from your phone.
- [Code with Claude Code or Codex](/north/guides/coding-tasks/): let north test each code change in a copy of your repository before you apply it.

## Work with north

- [Approve actions and set autonomy](/north/guides/approvals-and-autonomy/): answer cards, make rules and choose how much north decides.
- [Teach north about you](/north/guides/memory/): see and change what north remembers, and let it read your files.
- [Run tasks on a schedule with flows](/north/guides/flows-and-schedules/): make a flow, test it and run it on a schedule.
- [Choose the models north uses](/north/guides/choose-models/): set a model for each kind of work and see what each task cost.
